# RESPONSIBLE_USE_ADDENDUM.md

## Tier model

### Tier-0
Immediately public materials sufficient to regenerate released public figures and tables from released artifacts and/or seed-agnostic scripts.

### Tier-1
Public repository layer containing sanitized runners, masked parameter bands, declared environment files, provenance logging, and public regeneration scripts.

### Tier-2
Exact parameter locks, deterministic replay seeds, calibration-sensitive bands, and controlled validation materials. Tier-2 is not included in this public release.

## Withheld from the public release
- exact parameter locks
- deterministic replay seeds
- device-specific bindings
- hardware-tuning procedures
- hidden calibration-sensitive components

## Intended use
This repository is released for transparent scientific inspection, qualitative reproduction of public artifacts, and structured public review of the public Tier-0 / Tier-1 materials.

## Pause / update conditions
Tier-2 access terms may be paused or revised if:
- a platform-agnostic coherence uplift above the manuscript’s internal review threshold is independently reproduced,
- any credible cryptography-relevant speedup claim appears,
- unsupervised redistribution of gated materials is detected.
