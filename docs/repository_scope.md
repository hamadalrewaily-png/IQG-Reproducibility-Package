# repository_scope.md

This repository is a staged public starter package aligned with Appendix AQ of the IQG manuscript.

It is designed to:
- expose the public Tier-0 / Tier-1 scaffold,
- provide transparent file paths and repo structure,
- host released qualitative figure artifacts,
- support future insertion of sanitized public CSV/NPZ artifacts,
- preserve the public/gated boundary required by the manuscript.

It is not, in this starter release, a full disclosure of exact hidden calibration bands or deterministic replay materials.
